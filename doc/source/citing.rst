How to cite ``parsnip``
=======================

If you use **parsnip** in published work, please cite our article in the
*Journal of Open Source Software* [1]_. A suggested acknowledgment is:

  Data parsing for this publication utilized the parsnip library [1]_.

Reference
---------

.. [1] Jenna Bradley and Sharon C. Glotzer. "parsnip: Streamlined
   Crystallographic Data Parsing for Assembly Science and Engineering."
   *Journal of Open Source Software*, 11(124):10407, 2026.
   doi:10.21105/joss.10407.

The article is available from the `Journal of Open Source Software
<https://joss.theoj.org/papers/10.21105/joss.10407>`_, and the software
is archived on `Zenodo <https://doi.org/10.5281/zenodo.21268059>`_.
